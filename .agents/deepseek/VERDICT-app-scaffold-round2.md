## Identity trust (api/deps.py)

- Trusts exactly one header: `x-forwarded-email`, overridable by
  `AUTH_USER_HEADER`. `x-forwarded-user` / `x-databricks-user` /
  `x-databricks-user-email` are no longer read, so a spoofed header can no
  longer select an identity.
- No silent default. Missing header → `401`; only `APP_ENV=dev` opts into the
  `AUTH_DEV_USER` fallback, and that fallback principal is marked
  `authenticated=False` so it can never reach a write.
- `deps.py` never assigns a role. `_ensure_user` provisions new principals as
  `viewer` (least privilege) and reads the role back from `users`. Elevated
  roles are granted out-of-band only.
- Fail closed: any DB error in the identity/role lookup raises `503`
  (`"identity service unavailable"`) — never a role.

## Authorization

- `require_role`/`ensure_role` now enforce **authenticated** + role membership
  (`401` for unauthenticated, `403` for wrong role).
- `/api/orders/{id}/approve` now requires `approver` (was `trader`) and passes
  `ApprovalContext(approver_id=user.user_id)` to `record_approval` — the
  approver is always the authenticated principal, never read from body/query.
- `watchlists POST`, `orders/*`, and agent-chat write branches (watchlist/note)
  require an authenticated, non-dev-fallback principal.

## Error handling

- `api/routes/agent_chat.py` no longer serialises `str(exc)` (or
  `type(exc).__name__`) into responses. Failures return a stable code
  (`tool_failed`) + generic message; the exception is logged server-side via
  `loguru`.
- Audited every route for `str(e)`/`repr(e)`/exception-bearing f-strings in
  responses: `orders.py` (ValueError 422 and 503 paths), `market.py`,
  `signals.py`, and `watchlists.py` now return stable/generic messages and log
  server-side. Read-path freshness `detail` values retain only an exception
  class name (no message/host/SQL), consistent with the pre-existing envelope
  convention.

## Tests (tests/api/)

FastAPI `TestClient` with `db.lakebase.get_lakebase` (and the `agent.*` bound
references) overridden by an in-memory `FakeLakebase`; no Spark/Delta or network
is touched by the assertions. 8 tests across `test_auth.py`, `test_rbac.py`,
`test_error_handling.py`.
